# Security Policy

## Supported Versions

This project is currently in early development. Security improvements are welcome.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you find a security issue, please open a GitHub issue with the label `security`.

Do not include real passwords, API keys, tokens, or private information in bug reports.

## Educational Scope

This project is for learning Java and secure coding basics. It is not a production authentication system or password manager.
