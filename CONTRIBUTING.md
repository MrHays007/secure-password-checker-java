# Contributing

Contributions are welcome, especially beginner-friendly improvements.

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Run tests with `mvn test`.
5. Open a pull request with a clear explanation.

## Good First Contributions

- Improve README instructions
- Add more unit tests
- Improve password scoring logic
- Add more examples
- Refactor code for readability

## Commit Message Examples

```text
Add password strength scoring logic
Improve README setup instructions
Add test for empty password input
Refactor password analysis output
```
